# robinsdrums
Robin is learning to play the drums, here's some tools to help him learn some beats!

Live at https://robinsdrums.com: press Listen, hear the beat once, then play along. − / + change the tempo (5 BPM steps).

Static page (GitHub Pages). Drum sounds are synthesized in the browser (no sound files). Practice history stays in the browser that plays it ("save practice log" in How to practise).
